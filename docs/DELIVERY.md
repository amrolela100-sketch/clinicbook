# تسليم ClinicBook

## ما يمكنك استخدامه الآن

نسخة عربية RTL قابلة للتجربة، بتصميم مخصص وألوان هادئة وصور محلية وحركات دخول ورسوم متحركة تدعم تقليل الحركة. جميع المسارات الأساسية موجودة، والبيانات والإجراءات التشغيلية المحلية محفوظة في قاعدة SQLite.

**البدء:** افتح المعاينة، ثم «جرّب مساحة العمل». لتجربة إجراءات أخرى، غيّر الدور من بطاقة الحساب أو `/login`.

### وظائف محلية منفذة
- بحث وحجز فعلي مع معالجة 409 ومنع التداخل.
- قوائم المواعيد والإلغاء ضمن السياسة وعداد انتهاء الطلب.
- استقبال المريض والتحصيل النقدي؛ تأكيد/رفض الطلبات وتسجيل عدم الحضور.
- السجل الطبي والوصفة والطباعة/حفظ PDF من المتصفح.
- الدوام المتعدد الفترات والإجازات وتحذير المواعيد المتأثرة.
- إنشاء الأعضاء والفروع ضمن الحدود المحلية، وتعديل الرسوم.
- تقارير CSV، إعدادات المركز، إشعارات محفوظة، وطلبات تغيير الباقة.
- تسجيل مركز بثلاث خطوات، اعتماد إداري وتفعيل اشتراك يدوي داخل بيئة العرض.

## حدود مهمة

لا يوجد تكامل إنتاجي كامل مع Supabase حتى الآن. توجد migrations ومحوّل حجز وعملاء Supabase، لكن **ربط جميع المستودعات والإجراءات لا يزال عملًا برمجيًا مطلوبًا، وليس مجرد إضافة المفاتيح**. Google/Stripe/SMS/WhatsApp غير مفعّلة؛ التحديث المحلي polling كل 20 ثانية لا Realtime. يوجد فرع واحد لكل عضو في نموذج العرض، رغم دعم إنشاء فروع متعددة وإسناد العضو إليها.

لم يتم اختبار المشروع على Supabase المستضاف أو PostgreSQL 16. اختبارات PostgreSQL تمت على النسخة 17.11 مع Auth test shim، ولا تشكل إثبات امتثال صحي أو مراجعة أمنية شاملة.

**لا تستخدم بيانات مرضى حقيقية.** راجع README وقائمة بوابات الإطلاق في WORK_PLAN.md قبل أي نشر فعلي.
