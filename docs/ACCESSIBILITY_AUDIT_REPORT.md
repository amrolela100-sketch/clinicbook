# نطاق فحوص إمكانية الوصول المنتقاة (Playwright / axe)

**المشروع:** ClinicBook (رعاية أقرب. حياة أفضل.)  
**الأداة:** Playwright 1.64.0 و`@axe-core/playwright` 4.13.0.

**مرجع الشيفرة:** `1c84859`، **تاريخ التشغيل المتحقق:** 2026-11-13.

**الوسوم:** `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa`.

**النتيجة:** 11 اختبارًا في `accessibility.spec.ts` نجحت ضمن 38 اختبار demo؛
لم تبلغ فحوص axe مخالفات في العينات أدناه. **ليست شهادة امتثال WCAG أو فحصًا لكل الواجهات.**

---

## 1. العينة التي يفحصها الملف

هناك 10 مسارات وحالة درج المساعد على الصفحة الرئيسية، وليس 11 مسارًا مختلفًا.
اختبار `/login` يحلل تبويبي الدخول والتسجيل، فيصبح المجموع 12 استدعاء تحليل axe.
الاختبارات على بيانات demo وبإعداد `reducedMotion: reduce`؛ الحالات ليست كل
النوافذ والخطوات وأخطاء النماذج أو قياسات الجوال.

| رقم | الصفحة / المسار                                 | النطاق / الدور                                                        | الحالة   | عدد المخالفات (Violations) |
| --- | ----------------------------------------------- | --------------------------------------------------------------------- | -------- | -------------------------- |
| 1   | **الصفحة الرئيسية (`/`)**                       | عام (Hero, Search, Doctors, How-it-works)                             | **PASS** | 0 مخالفات                  |
| 2   | **استكشاف وفلترة الأطباء (`/search`)**          | عام (Toolbar, City/Specialty Filter, Grid)                            | **PASS** | 0 مخالفات                  |
| 3   | **الملف التعريفي للطبيب (`/doctors/doctor-1`)** | عام (Doctor bio, Slot Grid, Modal)                                    | **PASS** | 0 مخالفات                  |
| 4   | **تسجيل الدخول (`/login`)**                     | مصادقة (Sign-in / Sign-up Tabs, Demo roles)                           | **PASS** | 0 مخالفات                  |

## 2. فحوص إضافية محددة، لا تعميم لكل الواجهة

| الحد المختبر                                                           | ملف الاختبار                                                                                          |
| ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| وضوح outline على تحكمات عامة وبادجات صغيرة مقابل خلفياتها الفعلية      | [contrast.spec.ts](../tests/e2e/contrast.spec.ts)، [contrast.test.ts](../tests/unit/contrast.test.ts) |
| تسميات البحث و`aria-current` وحالة اليوم/الفترة المختارة               | [ui-accessibility.spec.ts](../tests/e2e/ui-accessibility.spec.ts)                                     |
| حوار تأكيد حجز المساعد: حبس التركيز والعودة للعنصر المختار وعزل Escape | [agent.spec.ts](../tests/e2e/agent.spec.ts)                                                           |
| هندسة حركة switch في RTL/LTR                                           | [ui-accessibility.spec.ts](../tests/e2e/ui-accessibility.spec.ts)                                     |
| نصوص الرئيسية عند 360px/390px وعدم تجاوز العرض                         | [typography.spec.ts](../tests/e2e/typography.spec.ts)                                                 |

هذه الفحوص لا تثبت حجم `44×44px` لكل زر، أو تباين AAA لكل النصوص، أو تشغيل جميع
قارئات الشاشة. `placeholder` وحده لا يُعتمد كتسمية حقل. نجاح axe يعني اجتياز
قواعد آلية محددة في DOM وحالة محددين، لا اجتياز كل معيار WCAG يدويًا.

## 3. ملف الاختبار البرمجي المعتمد

تم إنشاء وحفظ جناح الاختبارات الدائم في المشروع:

- [`tests/e2e/accessibility.spec.ts`](../tests/e2e/accessibility.spec.ts)
- يمكن إعادة تشغيله في أي وقت عبر الأمر:
  ```bash
   npx playwright test tests/e2e/accessibility.spec.ts
  ```

إعداد Playwright يشغّل demo على قاعدة SQLite معزولة. نتائج الاختبار لا تُنسب
إلى بيانات Supabase حقيقية، ولا تثبت صحة التنبيه الطبي أو أمان التشخيص.

## 4. المطلوب قبل ادعاء امتثال أوسع

- مراجعة يدوية للتنقل بالكيبورد وقراء الشاشة وتكبير النص وإعادة تدفقه.
- توسيع العينة إلى حالات الخطأ والنوافذ وخطوات التسجيل والوصفة وصفحات أخرى.
- توثيق viewport وإعدادات المتصفح وحالة الصفحة ومراجعة الشيفرة لكل نتيجة.
- إعادة الفحص بعد تعديل الواجهة. اللقطات القديمة ليست دليلًا على نتيجة تشغيل جديد.
