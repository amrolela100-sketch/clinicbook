# مصفوفة تتبع المتطلبات والادعاءات — audit #23

**مرجع الشيفرة:** `1c84859d8093e41ee2ac1d78e2b7c4fc1f09660e`، بتاريخ 2026-11-13.
تصحيح التوثيق لا يغيّر تنفيذ التطبيق أو الترحيلات. تُستخدم أسماء الملفات والدوال
بدل أرقام أسطر تتغير عند التنسيق.

هذه مصفوفة **تنفيذ واختبارات** وليست سجل تشغيل نهائيًا أو موافقة نشر. «منفذ»
يعني أن السلوك موجود في الشيفرة، و«مختبر» يخص الحالات المسماة فقط. نتيجة fixture
محلي أو SQL بدور مصطنع لا تُنسب إلى Supabase/Upstash الحقيقيين. تجميع أدلة تسليم
نهائية مرتبطة بـSHA عمل مستقل (#24).

## 4. قاعدة تحديث التوثيق

- كل ميزة حالية تُسند إلى مسار/دالة وإلى اختبار إن وُجد؛ غياب الاختبار يذكر صراحة.
- كل رقم اختبار أو تغطية يذكر مراجعة الشيفرة وتاريخها ونطاقها؛ لا يُبدل بأرقام تخمينية.
- السيناريو المقترح أو الهدف غير المقاس لا يُنقل إلى قائمة الميزات المنجزة.
- لقطات الشاشة صور توضيحية، لا نتيجة اختبار أو إثبات ترخيص/هوية.
- تُحدّث نسخ HTML عند تغيير مصادر Markdown؛ أسماء الطلاب والمشرفة وبيانات الغلاف محفوظة كما كانت.
